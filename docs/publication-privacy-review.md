# Public repository privacy review — 2026-09-28

This review describes the exact source tree prepared for public publication.
It does not certify that arbitrary future result files are safe to commit.

- The 26 committed invoice PNGs are generated test fixtures: six from
  `scripts/build_document_fixture.py` and twenty from
  `scripts/build_document_holdout.py`. Both scripts invent seller names,
  invoice numbers, dates and amounts, and draw a visible synthetic-use notice.
  The PNG bytes match the base64 payloads in their corresponding benchmark
  JSON files for all 26 samples. The PNGs contain no `tEXt`, `iTXt`, `zTXt`
  or `eXIf` metadata chunks. They are published to make the measured document
  acceptance reproducible; they are not customer invoices.
- The three committed Skill evaluation evidence bundles are generated by
  `scripts/run_skill_behavior_evals.py` from the committed test cases. Each
  Agent receives an isolated read-only workspace with a deterministic
  LocalPilot fixture. These transcripts are test artifacts, not captures of
  the author's normal shell history or conversations. The public history
  replaces a personal username found in some transcripts.
- The GB10 compatibility log replaces the assigned node label and home
  directory username. It contains model/config hashes and the failed startup
  trace, not SSH credentials or a model weight file.
- The public history has 36 commits. Author and committer metadata use the
  DingHappy GitHub noreply address. The personal username, personal email and
  assigned node label were removed from reachable historical blobs and
  commit metadata. This changes commit hashes; hashes recorded in old reports
  identify the pre-publication local history and may not resolve here.
- A scan of every reachable text blob in the publication branch found no
  private-key block, common GitHub/OpenAI/Hugging Face/AWS token format,
  bearer credential, email address or globally routable IPv4 address.
  `.env`, local profiles, raw runtime logs, model weights and isolated Agent
  workspaces are not tracked. Pattern scanning cannot guarantee that an
  arbitrary secret hidden in an unexpected format is absent.

Future evidence exports should receive the same review before they are added
to this public repository.
