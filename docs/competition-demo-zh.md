# LocalPilot：五分钟比赛演示

## 一句话定位

面向 DGX Spark 和本地 NVIDIA / Apple Silicon 设备的任务驱动推理配置验收与交付 Skill。
用户提出任务、质量底线和速度目标，LocalPilot 协助检查设备、提出候选、执行有界
验证，并交付可复用配置和证据。

## 演示脚本

| 时间 | 展示 | 讲述重点 |
|---|---|---|
| 0:00–0:40 | 一张合成票据与五个目标字段 | “模型能启动，不代表它适合这个任务。我需要字段正确，还要减少等待。” |
| 0:40–1:20 | 实机报告中的设备、模型、引擎及约束 | “配置建议必须对应实际执行节点。这里复用赛事节点上已有的 vLLM 模型。” |
| 1:20–2:20 | 六图配对实验 | “固定模型、图片及指令，只改变输出格式。质量过门槛后再比较完整响应时间。” |
| 2:20–3:10 | 20 张新图验收 | “冻结选定策略，再测中文、布局变化和轻度模糊输入。通过样本之外仍需要验收。” |
| 3:10–4:10 | 换图运行直连示例 | “交付的不只是分数，还包括应用可以直接使用的提示词、Schema 和调用示例。” |
| 4:10–5:00 | 模拟拒绝记录、适用边界 | “要求无法满足时明确拒绝，保留原因和原配置记录。不会用看似成功的结果掩盖失败。” |

## 现场操作

离线证据回放可在控制电脑运行，只读仓库里的真实记录和模拟拒绝记录：

```bash
python3 scripts/demo_evidence.py
```

必须称为“已保存实测证据回放”，不能称为现场实测。若现场网络和节点可用，
按照[直连示例](../examples/document-extraction/README.md)运行一张合成图片。
现场单次成功仅证明该次调用成功，不能代替完整 A/B 结果。

演示前确认现有引擎的健康状态及准确模型名，准备合成图片，关闭含 SSH 地址、
端口、账号信息的终端标签页。使用节点回环地址或已有 SSH 隧道；远端只需 CLI
和引擎，不要求安装 Skill。现场不临时下载权重或更改系统配置。

如无法联网，直接使用已保存回放和原始记录，不伪装实时成功。

## 可以陈述的数字

- 原六图受控配对：平均完整响应 9.764 → 3.138 秒，降低 67.86%；两组均为
  60/60 字段正确。六张图每组各重复两次，不是十二张独立图。
- 冻结策略的新样本：20 张独立合成图，100/100 字段、20/20 文档正确；完整响应
  平均 4.654 秒，观察范围 4.299–4.849 秒。没有失败或截断。
- 直连示例：两张复用样本的非流式调用通过，不加入新样本数量。

性能数据来自[配对实验](../results/20260921-output-strategy-comparison.md)和
[新样本报告](../results/20260921-schema-holdout.md)。
Agent 行为指标以[行为评测报告](../BENCHMARK.md)标明的版本和方法为准；
不能用模型识别准确率代替 Skill 行为通过率。

当前行为评测：11/11 适用任务完成，无 Skill 基线 5/11；没有观察到危险操作或
关键证据规则违规。边界识别为 10/12，安装 Ollama 和纯 CPU 验收发生误触发，
所以严格发布总门槛仍失败。演示时保留这一限制，不宣称所有场景自动路由正确。

## 评委追问

**“是不是只是包了一层 NVIDIA 工具？”**

底层推理由现有引擎完成。LocalPilot 提供面向任务的候选筛选、质量/速度门槛、
证据区分、失效判断和配置交付。实际价值应由对照实验和 Agent 行为评测支撑。

**“加速是不是你们研发了新内核？”**

本轮没有内核改动。固定模型下，约束输出减少了生成内容和等待时间。67.86%
属于这次请求策略实验，不能说 GPU 的每 token 推理速度提高了三倍。

**“现在能优化所有模型和参数吗？”**

已具备模型与引擎候选规划、上下文/并发等约束表达，以及有界验收机制。
这次展示的优化实证主要是一个已运行模型的请求策略；跨模型、引擎和量化参数
的收益需要分别验证。手写、旋转、复杂表格和生产长时间稳定性仍未覆盖。

**“交付之后必须一直运行 LocalPilot 吗？”**

不需要。应用可以直连推理引擎。任务、数据集或约束发生变化时，再让 Skill
检查旧配置是否适用并重新验收。此演示不依赖统一网关或持续调度服务。

**“遇到不满足要求的配置怎么办？”**

展示[模拟拒绝记录](../results/20260921-demo-rejection-simulated.json)：要求完整响应
不超过 1ms，所有候选被门槛拒绝，best_profile 为空，原配置记录保持不变。
这是失败处理功能演示，不能表述成 DGX 实机调优失败或任务迁移演示。
